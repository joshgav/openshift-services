# Policies

## Build a policy library

1. Fork <https://github.com/open-cluster-management-io/policy-collection> and sync it with a namespace in the hub cluster using one of the `application-policies-*` Applications.
2. Put a ManagedClusterSetBinding in the same namespace.
3. Put a Placement in the same namespace.
4. Put a PlacementBinding in the same namespace.

An example of a Perses dashboard with some policy-related metrics is also here.
